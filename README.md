ENEMY AT THE GATE

This UE4SS mod replaces the existing assaults in the game with over 100 customized assaults. The assault pool changes with story progress - weaker assaults phase out and more challenging ones appear; you won't see the easy assaults late game or vice versa. Assaults like a single Grunt, Crystallisk, or Lab Rat won't be a chore.


Configure the number of Assaults per week, from weekly to daily.  Simply open (EnemyAtTheGATE / CONFIG). There's also a debug option that lets you cycle through and test custom assaults.


If you want more control, the Assault files are editable. Edit the config files (EnemyAtTheGATE / ASSAULTS_NORMAL / HARD / CUSTOM). 

Tweak an assault to be easier or harder. Remove an assault you don't like. The mod provides access to some custom functions. Create fog for the assault duration and some Symphonists to go with it. Create a rift for Gatekeepers to walk into your base and watch them get jumped by a couple snowmen. 


Suggestions

To get the full experience of some of the late game assaults, test your base in the facility. It's not mandatory, but some of the weather effects are thematic and don't appear in portal worlds.


Installation

If ue4ss isn't installed, download it and unzip it. Copy that to your ABF win64 folder. It should be something like

C:\Program Files (x86)\Steam\steamapps\common\AbioticFactor\AbioticFactor\Binaries\Win64

ue4ss contents should be

[ue4ss folder]
dwapi.dll

Copy this to your Abiotic win64 folder. So if you navigate to that folder it should look like

...\Binaries\Win64

[d3d12]
[ue4ss]
AbioticFactor-Win64-Shipping.exe
dwapi.dll
...some other files...


If you have that, then you copy this project into the ue4ss\mods folder, so the mods folder looks like

...\Binaries\Win64\ue4ss\Mods

[BPML_GenericFunctions]
[EnemyAtTheGATE]
[...other folders...]

Trailer

A content mod that adds a lot of variation to the game. This includes


NEW ENEMIES - Enjoy a different experience on escaping the facility with over 90 new enemy variants. From small changes like an inverted gravity Pest to major ones like a ranged Security Bot that flings office supplies at you
PET VARIANTS - New pets like a Sow that shoots clouds of bees, a Pest that shoots frickin' laser beams, and a Magma Peccary that helps you cook. One setting also make pets easier to feed!
ENEMY PET VARIANTS - Be on the other side of an Electro Peccary or the cuddly embrace of a Leyak Pest. 

NEW EVENTS -  Over a dozen in-game events pop up during a playthrough. Some are one-time events like the Order staging a revenge assault, and some are ongoing like something new in the Canaan woods, or a blinding snowstorm in Voussoir. 
NEW TRADERS - 3 new traders appear alongside existing traders. One sells new consumables 
LESS PORTAL FARMING - some variants drop scarce items to reduce the number of portal farms to collect. 

GATEPal Updates - Journal entries to identify strengths and weaknesses of new variants
HARD MODE -  Five hard mode options in SETTINGS to make a more challenging experience. 



Compatibility 

Requires ue4ss. Preferably v3.0.1-1012+, but it is compatible with 3.0.1-553

Installing/uninstalling this mod should have no impact on your world save. Any variant pet you own will be a regular pet without the mod. 


Multiplayer
 
Compatible, but servers and clients must have this mod. (The same mod for both). If a client doesn't have the mod, the visuals are likely wildly bad and not a fun experience.


Feedback

Feel free to leave feedback on bugs, balance, or your experience in general. While not refined, my intent is to make this mod provide fun and challenging enemies, and not super hard ones. 

If you experience any crashes, try and capture the crash dump (if AF crashes it will usually put it in your clipboard), the crash folder, and ue4ss.log.
