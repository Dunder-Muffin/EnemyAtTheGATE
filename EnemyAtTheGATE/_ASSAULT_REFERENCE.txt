-- ===================================================================================
-- EM (EVENT MANAGER) FUNCTIONS  (Managers/EventManager.lua)
-- 
-- * Skim the assault file to see how these are used 
-- * Add additional functionality to an assault
--   > Set Weather
--   > Spawn enemies outside of the normal 'waves', in set locations
--   > Spawn large enemies *If spawned normally, they struggle to pathfind
-- 
-- * Each of these is a factory taht runs after a delay (ms)
-- * Use EM.Sequence() to run a bunch of these
--
-- ===================================================================================
-- EM.Sequence(fn, fn, ...) - run several of the below after OnStart
--
-- [WEATHER]
-- EM.AssaultWeather(weather, duration, delay) - 
--   * Fog, RadLeak, Spores, Blackout, BlackFog, ColdSnap
--   * Note: delay starts during prep phase (prep=20s before assault)
--       so you can have Fog roll in before assault phase                   
-- 
--
-- [SPAWNS] IN GENERAL, DROPS ARE KEPT 15-30m from the Bench]
--
-- EM.PestDrop(delay, opts) - A2 enemies. 
--   options { ... }
--     delay                ms this runs after the assault starts (30000 = 30sec)
--     opts.spawns          { pests, electros, volatiles, winters, carbonateds, rats, leyaks, magmas, enlighteneds }
--     opts.spawnInterval   ms delay between each NPC spawned. Min 200ms
-- 
--     opts.spawnRadius     min/max distance an NPC spawns from the bench. 
--     opts.minSpawnRadius  Best effort, may spawn closer if it fails to find a spot 
--     
--     opts.dilationStart   This slows an NPC's speed for X ms when it spawns
--     opts.dilationDelay   Main use: Order repel in on spawn. 
--                          Make a bunch of them slowly repel as a cool-factor + extra warning 
-- 
-- EM.PeccaryDrop(delay, opts) - spawns: { peccaries, sows, mushrooms, alphas, winters, electros, armoreds, volatiles }
-- EM.ExorDrop(delay, opts)    - spawns: { monks, exors, armoreds, pikemen, volatiles }
-- EM.SkinkDrop(delay, opts)   - spawns: { skinks, magmaSkinks }
--                               faction=x. (5 makes them friends with A2 entities)
-- 
-- EM.OrderDrop(delay, opts)   - spawns: { guards, grunts, medics, captains, breachers, snipers*, interfectors* } *don't have a spawn animation (repelling)
-- EM.GroupeDrop(delay, opts)  - spawns: { grunts*, rooks*, breachers* }
-- EM.RatDrop(delay, opts)     - spawns: { labRats, sappers, garageRat, flameRat }
-- 
-- EM.GatekeeperDrop(delay, opts)   - spawns: { phyters, mages, heavies, chieftains, witches, corruptBots }
--                                    NOTE: these spawn out of a single portal
--                                    fxDelay (portal open -> first NPC), firstSpawnInterval, emergeSound
--
--   THE PORTAL DROPS (GatekeeperDrop / RatDrop / ReaperPortalDrop) all aim
--   themselves at the target bench:
--     * the doorway faces the base (the FX is a flat plane - edge-on it is invisible)
--     * every NPC steps out pointing the same way
--     * the doorway DRIFTS forward along that facing over its lifetime, so it
--         reads as a gate advancing on the base and pushing bodies out of itself
--
--     opts.drift    uu the doorway travels. Omit for the default (100 for the GK
--                   and Nightrealm doors), 0 to pin it still, higher = faster slide
--
-- EM.SymphonistDrop(delay, opts)   - spawns: { symphonists } *Needs fog up
-- EM.CrystalliskDrop(delay, opts)  - spawns: { crystallisks }
-- EM.ReaperDrop(delay, opts)       - spawns: { reapers }
-- EM.GiantDrop(delay, opts)        - spawns: { tarasques, behemoths, yetis, bigfoots, bigogi, snowmen }
-- EM.LamogiDrop(delay, opts)       - spawns: { lamogis, bombs, bosses }
--
--   
-- EM.ReaperPortalDrop(delay, opts) - spawns: { reapers } - adds a Nightrealm portal flavor
-- EM.SpawnDarkLensMage(delay, opts)- spawns: { mages } - removes invuln
-- EM.PowerLeechBossDrop(delay, opts) - spawns: { powerLeeches }
--
-- EM.DirectDrop(delay, opts)  - A general purpose function to drop any unit,
--                               near the bench (5-10m). Don't use for giants
--
--
-- ===========================================================================================
-- [CROSSFIRE] - make two enemy factions fight each other, not just the base
-- ===========================================================================================
--
-- These work on EVERY EM.*Drop. Leave them out and nothing changes.
--
--   favoredEnemy      Faction name or number. Each NPC in the drop looks for an NPC
--                     of that faction near the bench and opens on a random one.
--                       > "Order", "Exor", "Robot", "Zombie", "Canaan", "Crystallisk"
--                       > (Pests and Exor share the "Exor" team)
--                       > No candidate nearby = it just runs the assault normally
--
--   favoredRadius     How far to look. Default 2500 (25m)
--
--   spawnAtWavePoint  Spawn at the DIRECTOR's own wave spawn point instead of around
--                     the bench. This is what actually creates a crossfire - otherwise
--                     both sides just converge on the bench from opposite angles
--                       > The whole drop lands on ONE point, together
--                       > It uses whichever wave is running when the drop fires
--                       > The game re-picks its spawn points each wave, and scatters
--                           each wave's NPCs randomly across them - so expect to land
--                           near SOME of that wave, not all of it
--
--   wavePointScatter  Spread around that point. Default 400 (4m)
--
-- * THE LOCK IS A ONE-SHOT. It lapses the moment that NPC lands its first hit, so it
--     trades a few blows and then goes back to the base. It does not babysit a grudge.
--
-- Example - Order waves, then Exor teleport in on top of them 10s later:
--
--   Wave1     = { "Grunt", "Grunt", "Grunt_Guard" },
--   Wave1Time = 2,
--   OnStart   = EM.ExorDrop(10000, {
--       spawns = { monks = 3, exors = 1 },
--       spawnAtWavePoint = true,
--       favoredEnemy     = "Order",
--   })
--
